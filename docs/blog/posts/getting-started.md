# Getting Started: A Guide to This Site

*January 30, 2024*

## Welcome Aboard!

If you're new here, this guide will help you navigate the site and make the most of all the features available.

### Site Navigation

The navigation is designed to be intuitive and accessible:

1. **Home**: The main landing page with an overview
2. **Blog**: All blog posts and articles
3. **Contact**: Get in touch or connect on social media

### Using the Theme Toggle

One of the best features of this site is the ability to switch between light and dark modes!

!!! tip "Theme Toggle"
    Look for the sun/moon icon in the top-right corner of the page. Click it to switch between light and dark themes. Your preference is automatically saved!

#### Light Mode
Perfect for daytime reading with a bright, clean interface.

#### Dark Mode
Easy on the eyes during evening hours with a sleek dark interface.

### Responsive Design

This website is fully responsive, meaning it works beautifully on:

- 💻 **Desktop**: Full-featured experience with all content
- 📱 **Mobile**: Optimized for touch and smaller screens
- 📱 **Tablet**: Perfect balance between desktop and mobile

Try resizing your browser window to see how the layout adapts!

### Accessibility Features

We've built this site with accessibility in mind:

- ✅ **Keyboard Navigation**: Navigate using Tab, Enter, and arrow keys
- ✅ **Screen Reader Friendly**: Proper semantic HTML and ARIA labels
- ✅ **High Contrast**: Both light and dark modes meet WCAG standards
- ✅ **Readable Fonts**: Clear typography optimized for readability

### Search Functionality

Use the search bar at the top to quickly find content across the entire site. It's fast and works even as you type!

### Blog Posts

Blog posts are organized chronologically and by category. Each post includes:

- 📅 Publication date
- 🏷️ Categories and tags
- 📖 Estimated reading time
- 🔗 Share buttons (coming soon)

### Adding New Content

!!! note "For Content Creators"
    To add a new blog post:
    
    1. Create a new `.md` file in `docs/blog/posts/`
    2. Add frontmatter with title and date
    3. Write your content in Markdown
    4. Update the blog index page
    5. Commit and push - GitHub Actions will deploy automatically!

### Tips for Best Experience

1. **Bookmark This Site**: Add it to your favorites for easy access
2. **Use Theme Toggle**: Switch themes based on time of day
3. **Enable Notifications**: Stay updated with new posts (if implemented)
4. **Share Content**: Tell others about posts you enjoy
